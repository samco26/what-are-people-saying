# The General Consensus

A personal, non-commercial web app that turns a controlled sample of online discussion about a subject into one clear consensus statement, with supporting themes and source counts.

## Status

Project planning and interactive visual design. Application code and live data integrations have not been built yet. The General Consensus is the working title; the GitHub repository remains `what-are-people-saying`.

The planned stack is Next.js, TypeScript and Tailwind CSS. GitHub stores project history; Vercel will host the initial application.

See [PROJECT.md](PROJECT.md) for version-one scope and milestones, [DESIGN.md](DESIGN.md) for the current visual direction, and [AGENTS.md](AGENTS.md) for development instructions.

## Development approach

Refine a visual mockup, implement a complete flow with clearly labelled sample data, and deploy the skeleton to Vercel early. Add AI and individual source integrations in separate milestones. Commit each working checkpoint.

There are currently no installation or run commands because the application has not been scaffolded.
